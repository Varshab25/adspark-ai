# AdSpark AI

A polished SaaS-style marketing demo built with React + Vite.

## Run locally

```bash
npm install
npm run dev
```

Then open:

```text
http://localhost:3000
```

## Includes

- landing page and SaaS-style product layout
- editable campaign form
- generated outputs for Instagram, Google Ads, LinkedIn, and WhatsApp
- copy buttons and reset flow
- sample-output demo mode without claiming live AI generation
